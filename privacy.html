سياسة الخصوصية

شرح مبسط لكيفية التعامل مع البيانات عند استخدام موقع FastSEO وخدمة تحليل الصفحات.

مقدمة

نحترم خصوصية زوار FastSEO. توضح هذه الصفحة بصورة مبسطة أنواع البيانات التي قد تمر عبر الخدمات اللازمة لتشغيل الموقع وكيفية استخدام بعض تقنيات التخزين.

تحليل المواقع

عند طلب تحليل، يتم إرسال عنوان الصفحة الذي تختاره إلى خدمة PageSpeed Insights لتنفيذ التحليل. في البنية الآمنة يتم تمرير الطلب عبر خادم الموقع ولا يتم وضع مفتاح API في كود المتصفح. قد تمر بيانات الطلب عبر مزود الخدمة الخارجي اللازم لتنفيذ التحليل وفق سياساته.

ملفات تعريف الارتباط والتخزين المحلي

قد نستخدم ملفات تعريف الارتباط أو التخزين المحلي لحفظ تفضيلات الواجهة مثل اللغة والمظهر. وقد تستخدم خدمات الإحصاءات أو الإعلانات التابعة لجهات خارجية تقنيات مشابهة وفق إعداداتها وسياساتها.

خدمات Google والطرف الثالث

قد يتصل الموقع بخدمات Google مثل Lighthouse أو PageSpeed Insights أو Google Analytics أو AdSense عند تفعيلها. تختلف معالجة البيانات حسب الخدمة وإعداداتها وسياسة مزودها.

الروابط الخارجية

قد تحتوي صفحات FastSEO على روابط لمصادر أو خدمات خارجية. لا يتحكم الموقع في سياسات الخصوصية الخاصة بهذه المواقع، ولذلك يُنصح بمراجعة سياساتها مباشرة.

التحديثات

قد يتم تحديث هذه السياسة عند إضافة وظائف أو خدمات جديدة. تاريخ آخر تحديث: 16 سبتمبر 2026.
